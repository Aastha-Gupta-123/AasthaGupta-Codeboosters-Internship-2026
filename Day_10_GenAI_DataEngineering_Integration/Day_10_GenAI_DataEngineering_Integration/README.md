# Day 10 - GenAI Data Engineering Integration

## Overview
This project integrates Data Engineering and Generative AI using Pandas, SQLite, SQL Analytics, and Groq LLM.

## Technologies Used
- Python
- Pandas
- SQLite
- Groq API
- Generative AI

## Dataset
- student_performance.csv
- college_notes.csv

## Workflow
1. Load datasets
2. Perform data quality checks
3. Store data in SQLite
4. Execute SQL analysis
5. Generate summaries
6. Use Groq AI for insights and recommendations
